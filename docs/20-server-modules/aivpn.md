# AIVPN

Дополнительный вход на сервере каскада. По умолчанию слушает UDP/8443, клиентская сеть `10.9.4.0/24`. Пульт загружает официальный бинарник v1.3.0 и сверяет SHA-256 до передачи. Ключ сервера создаётся на VPS и сохраняется при повторной установке. Трафик клиентов обслуживают те же таблицы split-routing и каскад, что и AmneziaWG.

Завести профиль на узле можно штатной командой `/usr/local/bin/aivpn-server --config /etc/aivpn/server.json --add-client <имя>`. Команда выдаёт секретную ссылку для приложения AIVPN. [Клиенты и параметры AIVPN](https://github.com/infosave2007/aivpn/tree/v1.3.0)
