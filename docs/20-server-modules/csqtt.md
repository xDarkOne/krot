# CSQTT

Отдельный вход каскада UDP/46000 и локальная административная панель CSQTT на TCP/46002. Крот извлекает сервер v2.5.0 из официального универсального APK и сверяет отдельно SHA-256 архива и бинарника. Для свежей установки пульт создаёт независимые пароли. Настройки узла находятся в `/etc/csqtt/csqtt.env` с правами root.

Административный порт закрыт внешним фаерволом Крота. Для управления используйте SSH-переадресацию до этого порта и браузер на своём компьютере. Профили для приложений выдаёт встроенная панель CSQTT. [Совместимые приложения CSQTT](https://github.com/amurcanov/csqtt/releases/tag/v2.5.0)
