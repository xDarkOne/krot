# SOCKS5 на выходе

Модуль `exit-socks` ставит Dante на выходе. Он слушает адрес `awg0` и принимает соединения только с туннельного адреса входа, с логином `krot-socks` и паролем, сгенерированным в хранилище владельца. Порт по умолчанию TCP/1080. Подключение к нему требует работающего основного межсерверного AWG.

Xray входа может использовать этот SOCKS для доменов из `modules.xray.socks_exit_domains`. При выборе полного каскада preset заполняет этот список для нескольких сервисов Google AI. Для публичного SOCKS5 нужен отдельный сервис и собственные правила доступа.
