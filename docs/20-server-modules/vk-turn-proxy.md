# VK TURN Proxy

Крот может развернуть серверную часть VK TURN Proxy на входе и направить её к локальному WireGuard. Исходники берутся с проверенного коммита upstream. Во время установки создаётся собственный ключ для режима `wrap-srtp`. Для реального подключения нужен совместимый клиент VK TURN Proxy и параметры владельца, включая его собственный звонок VK. [Upstream и клиентские приложения](https://github.com/cacggghp/vk-turn-proxy/tree/37d6607f5c8f3bc4c84595874c6dafa0f5b1d847)

Порт сервера по умолчанию UDP/56000. Профиль WireGuard создаёт команда `krot clients add <вход> <имя> --iface wg2`. Настройки транспорта находятся в `/etc/vpnkit/vk-turn.env` на входе. Файл доступен только root.
