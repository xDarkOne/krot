# vpn-bot — Telegram-бот администратора

**Роли:** entry, solo. **Зависит от:** base-host, monitoring. **По умолчанию выключен.**
**Код:** [agent/vpn-bot/](../../agent/vpn-bot/)

Бот в Telegram для администратора: состояние сервера, клиенты подписки (выдать ссылку, завести, удалить) и статистика трафика. Токен и получатели — те же, что у оповещений мониторинга (`krot alerts set`): отдельного бота заводить не нужно. Отвечает только чатам из списка получателей.

## Что умеет

- **Состояние** — нагрузка, память, диск, какие службы живы (xray, hysteria2, sing-box, nginx, warp-ru, MTProto, таймеры), активные пиры AmneziaWG.
- **Клиенты** — список клиентов подписки; карточка со ссылкой подписки и ссылками маршрутов (Happ, INCY); создание клиента (бот спросит имя); удаление с подтверждением. Работает через `vpnkit-gen.py`, то есть тот же реестр `/etc/vpnkit/users.json`, что и команды пульта.
- **Трафик** — по клиентам AmneziaWG за сутки, неделю, месяц.

Профили AmneziaWG бот не создаёт: ключи клиентов хранятся только у вас на компьютере (пульт: `krot clients add`). Так не возникает двух источников правды, а `krot clients resync` продолжает работать. Бот показывает имена таких клиентов и их трафик.

## Файлы и службы

- `/usr/local/sbin/vpn-bot.py`, `vpn-bot.service` — сам бот (долгий опрос Telegram, без внешних библиотек).
- `/usr/local/sbin/vpn-stats.py`, `vpn-stats.timer` (каждые 5 минут) — сбор трафика: приращения `awg show <iface> dump`, имя клиента из строки `# name:` в конфиге. Служебные пиры без имени (каскад) не считаются.
- `/var/lib/vpnkit/stats.db` — SQLite, хранится 90 дней.

## Требования

Сервер входа должен доходить до `api.telegram.org`: в каскаде Крот направляет сети Telegram через выход, поэтому бот работает и на узле в России. Перед установкой проверяется, что токен принят Telegram.

## Откат

Откат прогона останавливает бот и таймер, если их поставил этот прогон. Удаление оставляет базу статистики.
