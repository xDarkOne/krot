# Веб-панель в Telegram

Включите модуль `vpn-panel` в составе установки. Он использует HTTPS-имя подписок, бота из настроек оповещений и личный Telegram ID владельца. После установки откройте личный чат с ботом, отправьте `/menu` и нажмите **Панель**. API проверяет подпись Telegram, свежесть данных и ID из настроек администратора. [Формат подписи Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)

Панель создаёт и удаляет подписки в штатном реестре Крота, показывает трафик профиля за сутки, выдаёт ссылки и показывает список устройств, если приложение присылает заголовок `Hwid`. В истории хранится производный идентификатор, тип устройства и время последнего обновления. Запись устройства удаляется отдельно или сбрасывается для всей подписки. Запросы подписок и токены исключены из журнала nginx.

Для профиля можно указать день оплаты от 1 до 31. Напоминание приходит администратору, который задал день, после 10:00 по часовому поясу узла. В коротком месяце день переносится на последнее число. Настройка не меняет доступ клиента к VPN.

Установка создаёт локальный HTTP API и публикует его за nginx. Состояние устройства и напоминаний хранится в `/var/lib/vpnkit/panel.db`. Штатный модуль резервных копий включает панель в зашифрованную копию.

Пока панель установлена, бот и карточка панели дают ссылку `/g/<токен>/incy`. Она перенаправляет в INCY с URL актуальной подписки. Ссылку следует передавать только владельцу соответствующего профиля.

Если на узле установлен вход AmneziaWG 3.1, при создании подписки в панели можно сразу выпустить AWG-профиль. Панель хранит этот профиль на VPS владельца в закрытом реестре и отзывает его пир вместе с комбинированной подпиской. Профили, выпущенные настольным приложением, продолжают обслуживаться пультом.
