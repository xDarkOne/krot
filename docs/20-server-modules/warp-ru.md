# warp-ru — российский трафик через Cloudflare WARP

**Роли:** entry. **Зависит от:** cascade-awg0, split-routing, xray, amneziawg.
**Код:** [agent/warp-ru/](../../agent/warp-ru/)

Российские сайты (банки, госуслуги) настороженно относятся к адресам хостингов. Модуль заставляет «российский» трафик клиентов выходить с адреса Cloudflare WARP, а не с адреса сервера входа. Если WARP недоступен, сторож сам возвращает этот трафик на прямой выход — клиенты ничего не замечают.

## Как устроено

- `/usr/local/sbin/warp-ru` — скрипт: поднимает интерфейс `awgw` (AmneziaWG до Cloudflare), ведёт таблицу маршрутизации 201, команды `init`, `start`, `stop`, `watch`, `renew`.
- `/etc/warp-ru/account.json` — анонимный аккаунт WARP, заводится при установке (запрос идёт через каскад, потому что напрямую с хостинга Cloudflare часто не отвечает).
- `/etc/warp-ru/i1.txt`, `endpoints` — параметры обфускации и точки входа Cloudflare.
- `/etc/warp-ru/bypass-domains` — домены, которым WARP не нужен (идут напрямую). Свой список повторная установка не затирает.
- `warp-ru.service` — служба-сторож: проверяет связь и переключает таблицу 201 между `awgw` и прямым выходом.

### Маршрутизация

| Что | Правило |
|---|---|
| внешние пакеты самого туннеля WARP | fwmark 0x5 → main (приоритет 201) |
| точки входа Cloudflare, bypass-домены | → main (202) |
| российский трафик xray (outbound `ru-exit`, метка 0x4) | → таблица 201 (203) |
| российский трафик ядерных клиентов (метка 0x1) | → таблица 201 (204) |

Шлюз прямого выхода определяется из основной таблицы динамически — модуль не привязан к адресу хостинга, поэтому переживает клонирование сервера.

`vpnkit-gen.py` добавляет outbound `ru-exit` в конфиг xray, когда существует `/etc/warp-ru/account.json`; без него российский трафик идёт через `direct`.

## Проверка и откат

Проверка: служба активна, есть `awgw`, есть правило `fwmark 0x1 → 201`, в xray есть `ru-exit`. Отсутствие связи с WARP в данный момент не считается ошибкой.

Откат: служба останавливается и отключается, аккаунт удаляется (по снимку), конфиг xray пересобирается без `ru-exit`.

## Ловушки

- Если режим включён, а Cloudflare недоступен, трафик не пропадает — сторож держит прямой выход.
- `awg set listen-port` и подобные правки на живом `awgw` не нужны; перезапуск — только службой.
