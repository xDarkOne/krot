# Требования и ограничения

Команда `krot requirements` выводит этот документ в виде таблицы, а `krot check <узел>` проверяет конкретную машину.

## Серверы

### Платформа
| | Поддерживается | Не поддерживается |
|---|---|---|
| ОС | Ubuntu 24.04, 26.04; Debian 12, 13 | другие дистрибутивы; 32-битные системы |
| Архитектура | amd64, arm64 | armv7 и другие 32-битные |
| Виртуализация | KVM, VMware, Hyper-V, выделенный сервер | **OpenVZ, LXC** — нельзя загрузить свой модуль ядра (AmneziaWG) |
| Ядро | с заголовками в репозитории (`linux-headers-$(uname -r)`) | ядро хостера без заголовков; Secure Boot с принудительной подписью модулей |
| Сеть | публичный IPv4, неограниченный UDP | NAT-VPS без своих портов; хостеры, режущие UDP |
| Доступ | root по SSH (ключ или пароль на первый вход) | — |

`check` проверяет:
- `systemd-detect-virt` → kvm/none;
- `apt-cache policy linux-headers-$(uname -r)` → пакет есть;
- `mokutil --sb-state`;
- свободные порты;
- наличие чужих служб: Docker, nginx, службы на 443 и 80;
- что внешний адрес совпадает с адресом интерфейса (иначе за NAT).

### Ресурсы
| Роль | Минимум | Рекомендуется |
|---|---|---|
| **exit** | 1 vCPU, 512 МБ RAM + 1 ГБ swap, 5 ГБ диска | 1 vCPU, 1 ГБ, 10 ГБ |
| **entry** | 1 vCPU, 1 ГБ RAM + 2 ГБ swap, 10 ГБ | 2 vCPU, 2 ГБ, 20 ГБ |
| **solo** | 1 vCPU, 1 ГБ + 2 ГБ swap, 10 ГБ | 2 vCPU, 2 ГБ, 20 ГБ |

Одного ядра хватает для 20–30 клиентов; канал между узлами может заканчиваться раньше CPU.

Пиковая нагрузка — только сборка модуля ядра AmneziaWG (5–15 минут при установке и обновлении ядра).

### Стоимость модулей (добавочно)
| Модуль | RAM | Диск | Прочее |
|---|---|---|---|
| amneziawg | ~0 | ~600 МБ на сборку | заголовки ядра |
| xray | 35–60 МБ | 40 МБ | — |
| hysteria2 (sing-box) | 20–50 МБ | 40 МБ | — |
| mtproxy (MTProxyL) | ~30–60 МБ (telemt, zapret2; бот по желанию) | ~40 МБ | — |
| gemini | ~0 (таймер) | мало | — |

### Сеть и порты (открыть у хостера, если есть внешний фаервол)
| Узел | Порты |
|---|---|
| вход / один сервер | TCP 22, 80, 443, 4443 (XHTTP), порт PQ; UDP 443 (hysteria2), порт входа AmneziaWG |
| выход | TCP 22, 80 и 443 (витрина, если задано имя); UDP порт туннеля awg0 |

Порты AmneziaWG и PQ пульт выбирает случайно из 20000–60000. Если у хостера свой внешний фаервол, откройте этот диапазон (TCP и UDP) или выключите фаервол хостера: сервер закрывает лишнее сам.

## Домены
- Свой домен нужен для подписки, VLESS, Hysteria2 и прокси Telegram (без него — только AmneziaWG). DNS может быть у любого провайдера; Cloudflare мастер умеет настраивать сам.
- Записи A — **без проксирования** (DNS only): туннели и MTProto не проходят через HTTP-прокси.
- Имена по умолчанию: `es` (туннели) и `ru` (подписки и маска Telegram) → вход или единственный сервер; `web` (WEB Proxy Telegram) → туда же, по желанию; `en` → выход, по желанию. Поддомены можно переназвать.
- Перед выпуском сертификатов мастер проверяет, что каждое имя резолвится в свой сервер у публичных резолверов.

## География (почему именно так)
- **entry** — в России, у провайдера, которого не режут у мобильных операторов. Клиенты видят российский адрес, а российские сайты работают напрямую.
- **exit** — за границей. Перед покупкой проверить, каким Google видит адрес: `curl -s https://www.youtube.com/?hl=en | grep -o '"GL":"[A-Z]*"'`. Если Google видит адрес как `RU`, для Gemini может понадобиться Smart-DNS.
- **solo** — только зарубежный сервер. Ограничения:
  - клиенты подключаются к зарубежному адресу, а такие режут первыми;
  - российские сайты, закрытые для зарубежных адресов, открываются только при разделении на клиенте (правила подписки делают это сами);
  - не работает при белых списках мобильных операторов.

## Пульт (ПК администратора)
Приложение с окном или CLI `krot` для Windows 10+, macOS (Intel и Apple Silicon) или Linux (amd64/arm64; окну нужны GTK3 и WebKitGTK 4.1). Нужны SSH-доступ к серверам и интернет.

## Что система не умеет (честно)
- IPv6 для клиентов не поддерживается: выход только IPv4, AAAA фильтруется.
- Проверку «работает ли на мобильном операторе» автоматически не сделать. Нужен человек с телефоном. Инструмент выводит пошаговую проверку ([P-09](60-pitfalls.md)).
- Smart-DNS для Gemini — чужие сервисы, они регулярно отваливаются. `ai-dns-switch` перебирает их, но может не найти ни одного живого.
