# Безопасность

## Модель угроз
| Кто | Чего не допускаем |
|---|---|
| Цензор (ТСПУ) | опознать и заблокировать входы; вычислить выход |
| Сканеры интернета | найти панели и открытые службы; подобрать пароль SSH |
| Клиент VPN | попасть во внутренние службы сервера (панели, API, socks), в сети других клиентов |
| Утечка с компьютера пользователя или из репозитория | получить ключи, токены, профили клиентов |
| Сторонний установщик | выполнить непроверенный код от root, открыть порты, увести трафик мимо каскада |

## Что делает установщик
- **Фаервол:** policy drop на input и forward, открыто только нужное модулям; свои таблицы `inet vpnkit_*`, без `flush ruleset` ([P-01](60-pitfalls.md)).
- **SSH:** после перевода на ключ вход по паролю выключен, root — только по ключу; fail2ban. Пароль root используется один раз и нигде не хранится.
- **Обновления безопасности** ставятся сами (`unattended-upgrades`).
- **Внутренние службы** (API telemt, метрики, socks xray, вход WEB Proxy) слушают только петлю.
- **`PRIVATE → block` в xray:** клиенты подписки не достают внутренние службы сервера ([P-17](60-pitfalls.md)); `doctor` это проверяет.
- **Маскировка:** незнакомый клиент на 443 видит обычный сайт-витрину; XHTTP — за настоящим TLS; отпечаток по умолчанию `ios` ([P-51](60-pitfalls.md)); Reality как клиентский вход не предлагается ([P-52](60-pitfalls.md)).
- **Резервные копии** шифруются открытым ключом пульта: сервер создаёт их, но прочитать не может.

## Правила кода
1. **Секреты генерирует пульт** криптостойким генератором и хранит в зашифрованном `secrets.age` (ключ — `~/.vpnkit/age.key` или пароль). В `inventory.yaml` секретов нет.
2. **На узлах** секреты лежат только в файлах 600 (каталоги 700), в службы передаются через `EnvironmentFile=`/`LoadCredential=`. Никогда — в аргументах командной строки или в журналах.
3. **Вывод** пульта и журналы маскируют всё, что похоже на ключ, UUID или токен. Правила — те же, что в `tools/redact-check.sh`; он же проверяет репозиторий перед каждым коммитом и в CI.
4. **Сторонние бинарники** — только по закреплённой версии со сверкой sha256. Сторонние установщики не запускаются; исключение — MTProxyL по закреплённому тегу с явными параметрами ([P-53](60-pitfalls.md)).
5. **Каждая открытая наружу служба** описана в манифесте модуля (порт и зачем).
6. **Данные с узлов** попадают в окно приложения только как текст.

## Что хранится у пользователя
| Где | Что | Чем защищено |
|---|---|---|
| `~/.vpnkit/age.key` | ключ пульта | права 600; **копию держать отдельно** (менеджер паролей) — без него не расшифровать ни хранилище, ни копии |
| `secrets.age` рядом с `inventory.yaml` | ключи серверов и клиентов, токены | шифрование age |
| `~/.vpnkit/keys/` | SSH-ключи к серверам | права 600 |
| `~/.vpnkit/clients/` | профили клиентов (QR, ссылки) | права 600 |
| `~/.vpnkit/backups/` | резервные копии серверов | шифрование age |
