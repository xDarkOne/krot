# Как пользоваться Кротом

Крот ставит ваш собственный VPN на арендованные серверы и потом помогает его обслуживать: раздавать подключения, обновлять, делать резервные копии. Всё хранится у вас на компьютере, своего сервера и учётных записей у программы нет.

Есть два способа работы:
- **приложение с окном** (Windows, macOS, Linux) — для большинства;
- **командная строка** `krot` — те же действия командами, для опытных и автоматизации.

Оба используют одни и те же файлы, поэтому их можно чередовать.

## 1. Какую схему выбрать

| | Каскад (два сервера) | Один сервер |
|---|---|---|
| Серверы | VPS в России (вход) + VPS за границей (выход) | один VPS за границей |
| Что видит оператор связи | подключение к российскому адресу | подключение к зарубежному адресу |
| Белые списки мобильных операторов, блокировка зарубежных адресов | переживает | не работает |
| Российские сайты (Госуслуги, банки) | открываются с российского адреса | закрытые для заграницы — только через правила подписки на устройстве |
| Цена и время | два сервера, около 40 минут | один сервер, около 25 минут |

Если сомневаетесь, но бюджет позволяет, берите каскад. Если VPN нужен в основном дома и по Wi-Fi, одного сервера обычно хватает. Перейти с одного сервера на каскад позже можно, но клиентам AmneziaWG придётся выдать новые профили.

## 2. Что понадобится

- **Серверы (VPS):**
  - виртуализация KVM (не OpenVZ/LXC);
  - Ubuntu 24.04/26.04 или Debian 12/13;
  - от 1 ГБ памяти, публичный IPv4, доступ root по паролю — его присылает хостер.
- Сервер, к которому подключаются устройства (вход каскада или единственный сервер), должен **открываться из России без VPN**. Мастер проверит это сам.
- **Домен — по желанию, но лучше с ним.** Без домена будет только AmneziaWG. Подписке, VLESS, Hysteria2 и прокси Telegram нужен домен: сервер маскируется под обычный сайт. Подойдёт любой недорогой домен; DNS удобно держать в Cloudflare (бесплатно).
- **Бот в Telegram — по желанию**, для оповещений о поломках.

Подробные требования — команда `krot requirements` или [40-requirements.md](40-requirements.md).

## 3. Установить приложение

Скачайте сборку для своей системы со страницы [Releases](https://github.com/xDarkOne/krot/releases/latest):

- **Windows 10/11:** `krot-app-…-windows-amd64.exe` (на ARM-ноутбуках — `-arm64`). Нужен WebView2 — в Windows 10/11 он уже есть. Сборка не подписана, поэтому SmartScreen предупредит: «Подробнее» → «Выполнить в любом случае».
- **macOS:** `krot-app-…-macos-universal.zip`. Распакуйте и перенесите `krot.app` в «Программы». Первый раз откройте через правый клик → «Открыть»: сборка не подписана.
- **Linux:** `krot-app-…-linux-amd64.tar.gz` (или `-arm64`). Нужны GTK3 и WebKitGTK 4.1 (Debian/Ubuntu: `sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0`). Распакуйте и запустите `./install.sh` — появится ярлык в меню.

Командная строка — файлы `krot-cli-…` для той же системы. Контрольные суммы — `SHA256SUMS`.

Собрать самому — [app/README.md](../app/README.md).

**Обновления самого Крота.** Приложение при запуске (и раз в 6 часов) проверяет последний релиз. Если вышла новая версия, сверху появится полоса «Доступна новая версия Крота» с кнопкой «Обновить»: приложение скачает сборку, сверит её контрольную сумму, поставит на место старой и перезапустится. Командная строка обновляется командой `krot self-update` (`--check` — только проверить). Если папка с программой закрыта на запись, кнопка ведёт на страницу релиза.

## 4. Первая установка — мастер

**Перед началом выключите VPN на этом компьютере**: мастер проверяет, что сервер виден из России.

Откройте приложение и нажмите **«Новая установка…»**.

1. **Схема.** Каскад или один сервер (см. раздел 1).
2. **Сервер (или вход и выход).** Введите имя для себя (`ru`, `eu`, `vpn`), IP-адрес и пароль root.
   - **Проверить** — мастер убедится, что сервер доступен и подходит. Если нет, он объяснит почему: например, «нужен тариф KVM».
   - **Перевести на ключ** — мастер создаст ключ, проверит вход по нему и только после этого отключит вход по паролю. Пароль нигде не сохраняется.
   - Выход каскада может быть не виден из России, это нормально: мастер будет ходить к нему через вход.
3. **Домен.** Мастер покажет, какие A-записи создать: по умолчанию `es.` и `ru.` на вход (или на единственный сервер) и `en.` на выход. В Cloudflare записи должны быть **без проксирования** (серое облако).
   - Записи можно создать вручную и нажать «Проверить записи».
   - Или дать токен Cloudflare с правом правки DNS этой зоны — тогда мастер создаст записи сам. Токен используется один раз и не сохраняется.
   - Без домена снимите галочку «У меня есть домен».
4. **Состав.** Отметьте, что ставить. У каждого модуля написано, что он делает, зачем нужен и чего стоит.
   - **Основа** (защита сервера, сертификаты, резервные копии, мониторинг) — включена; основу сервера выключить нельзя.
   - **Каскад** — ставится сам в схеме с двумя серверами.
   - **Способы подключения** — нужен хотя бы один:
     - *AmneziaWG* — приложение AmneziaVPN, профиль по QR; домен не нужен;
     - *VLESS* и *Hysteria2* — входы подписки;
     - *Подписка* — одна ссылка на все входы для Happ, v2rayNG, Hiddify;
     - *Прокси для Telegram* — Telegram без VPN-приложения, удобно родным.

   Под галочками сразу видно, что получится: модули, которые нужны выбранным, включаются сами («нужен для …»), а то, что поставить нельзя, показано с причиной («нужен домен»).
5. **Установка.** Мастер покажет план и поставит модули по одному. Перед каждым шагом делается снимок, и если связь с сервером пропадёт или проверка не пройдёт, шаг откатится сам. При ошибке нажмите **«Продолжить»** — установка начнётся с упавшего шага. Сборка модуля ядра AmneziaWG занимает 5–15 минут, это нормально.
6. **Готово. Сохраните ключ пульта** — мастер покажет, где он лежит (`~/.krot/age.key`). Без него не расшифровать ни настройки, ни резервные копии. Положите копию в менеджер паролей.

Что мастер записал на диск:
- `~/.krot/cascade/inventory.yaml` (или `~/.krot/solo/...`) — описание серверов, секретов в нём нет;
- `secrets.age` рядом — зашифрованные ключи и пароли;
- `~/.krot/keys/` — SSH-ключи к серверам.

## 5. Раздать подключения

Выберите в списке слева сервер, к которому подключаются устройства (вход каскада или единственный сервер). Там три колонки:

| Колонка | Для кого | Приложение на устройстве |
|---|---|---|
| **AmneziaWG** | телефон или компьютер, весь трафик | AmneziaVPN (5.0.2 и новее) |
| **Подписка** | телефон или компьютер, все входы одной ссылкой | Happ, INCY, v2rayNG, Hiddify |
| **Telegram** | только Telegram, без VPN-приложения | сам Telegram: открыть ссылку → «Подключить прокси» |

Введите имя (например, `mama-phone`) и нажмите **«Добавить»**. В карточке клиента — QR-код и ссылка: QR сканируется приложением, ссылку можно переслать. **«Удалить клиента»** сразу отключает его профиль или ссылку.

Роутеры приложение не настраивает. Роутер с OpenWrt (podkop, Forkozz и т. п.) подключается как обычный клиент: выдайте ему профиль AmneziaWG или ссылку подписки.

## 6. Обслуживание

- **Состояние сервера** — экран узла: система, память, диск, установленные модули и итог проверок мониторинга. Кнопка **«Проверить все»** слева опрашивает все серверы.
- **Добавить модуль позже** — экран узла → «Модули установщика» → **«Установить»** (нажать дважды: второе нажатие — подтверждение). Так же — **«Переустановить»**, если модуль ведёт себя странно.
- **Обновления** — когда в пульте новее версия модулей, сверху появится полоса «Доступны обновления» с кнопкой **«Обновить»**. Каждый модуль обновляется с тем же откатом, службы перезапускаются, только если их настройки действительно поменялись. **«Версии»** показывает, что стоит на серверах и что вышло у авторов.
- **Оповещения** — кнопка **«Оповещения»**: создайте бота у @BotFather, вставьте токен, напишите боту что-нибудь, выберите себя в списке и нажмите «Отправить тест и сохранить», затем «Применить на узлах». После этого мониторинг пишет в Telegram, если что-то сломалось.
- **Резервные копии** — серверы делают их каждую ночь, зашифрованными вашим ключом пульта. На экране узла **«Забрать свежую копию»** скачивает и проверяет копию (`~/.krot/backups/<узел>/`). **«Восстановить клиентов»** возвращает клиентов подписки и Telegram из копии — например, после переезда на новый сервер.
- **Переезд на новый адрес** — клонируйте сервер у хостера, зайдите на клон и выполните `relocate-ИМЯ` (имя узла). Команда сама перепишет прошитые адреса, на соседе по каскаду сделает то же и подскажет, какие записи домена поменять. Подробнее — [relocate](20-server-modules/relocate.md).

## 7. Если что-то пошло не так

- **Шаг установки упал.** Он уже откатился. Прочитайте последние строки журнала — там причина. Исправьте её (например, DNS-запись) и нажмите «Продолжить».
- **Связь с сервером пропала во время установки.** Сервер сам вернёт всё как было («мёртвая рука»), даже если пульт так и не подключился: у каждого модуля свой срок, от 3 до 30 минут (дольше всех ждёт сборка модуля ядра).
- **Мониторинг ругается.** Экран узла покажет, какие проверки не прошли. Через командную строку подробнее: `krot doctor <узел>`.
- **Сервер умер.** Нужен новый сервер, ключ пульта и резервная копия: `backup extract`, затем `restore clients` и `clients resync` (раздел 8).

## 8. Командная строка

Все действия окна есть и в CLI: файл `krot-cli-…` из релиза (переименуйте в `krot`) или `go build -o krot ./cmd/krot`. Справка — `krot help`.

**Первая установка без окна:**

```
cp inventory.solo.example.yaml inventory.yaml     # или inventory.cascade.example.yaml
# поправить адреса, имена и домен в inventory.yaml
krot catalog solo                               # что ставится по умолчанию, что можно включить
krot secrets init --key                         # хранилище на ключе пульта (~/.krot/age.key)
krot precheck 203.0.113.10 solo                 # подходит ли сервер (спросит пароль root)
krot bootstrap vpn                              # перевести на ключ, отключить пароль
krot deploy                                     # покажет план и поставит по шагам
```

Выбор модулей — в `inventory.yaml`, у узла: `modules.<имя>.enabled: true` или `false`. Если не указано, действует умолчание каталога. После правки снова выполните `krot deploy`: он поставит только недостающее.

**Каждый день:**

```
krot clients add vpn mama-phone                 # AmneziaWG: профиль и QR в терминале
krot clients add vpn mama-phone --sub           # подписка
krot clients add vpn mama --tg                  # прокси Telegram
krot clients list vpn [--sub|--tg]
krot clients del vpn mama-phone
krot status all                                 # сводка по серверам
krot update                                     # обновить отставшие модули
krot backup pull all                            # забрать и проверить резервные копии
```

Файл узлов по умолчанию — `inventory.yaml` в текущей папке; другой — `-i путь`.

## 9. Честные ограничения

- Проверить, пройдёт ли подключение через конкретного мобильного оператора, программа не может — проверьте с телефона.
- Профиль AmneziaWG содержит IP сервера: при переезде на другой адрес клиентам AmneziaWG нужен новый профиль. Подписка и прокси Telegram ходят по имени и переезд переживают.
- Без подписи кода Windows и macOS предупреждают при первом запуске приложения.
