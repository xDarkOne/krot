vpnkit — свой VPN на своих серверах (окно для Linux)

Нужны GTK3 и WebKitGTK 4.1:
  Debian 12+ / Ubuntu 22.04+:  sudo apt install libgtk-3-0 libwebkit2gtk-4.1-0
  Fedora:                      sudo dnf install gtk3 webkit2gtk4.1
  Arch / CachyOS / Manjaro:    sudo pacman -S gtk3 webkit2gtk-4.1

Установка для себя (ярлык в меню):  ./install.sh
Или просто запустить:               ./vpnkit-app

Как пользоваться — docs/USAGE.md в репозитории проекта.
